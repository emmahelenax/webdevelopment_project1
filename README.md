**About the Application**

The Stable Worker's Daily Schedule is an application where he workers may add their daily tasks onto the application and keep track on what is done and what isn't. This is to keep everything clear on what horse has had their meal, water, medicine etc. so there is no overlap between the workers.

**Technologies Used**

- HTML to make the overall base and structure of the page
- CSS to style the page
- JavaScript to provide functionality
- localStorage to save the data in browser so tasks don't get lost
